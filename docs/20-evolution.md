# Отбор агентов

Есть два отбора. Они не смешиваются.

- **Внутренний отбор по качеству** работает уже сейчас. Худшие разведчики правда уходят в архив, лучшие копируются.
- **Денежный отбор** по реальной выручке остаётся HOLD, пока нет настоящих продаж. Тестовые платежи не считаются. Симуляция на учебных данных доступна отдельно и помечена.

## Балл разведчика

Считает сервер (`scoreStrategies` в `core/evolution.ts`) по идеям текущего поколения. Модель на балл не влияет. Все части целые, от 0 до 1000.

| Часть | Что значит                                                         | Вес |
| ----- | ------------------------------------------------------------------ | --- |
| P     | доля идей, принятых критиком                                       | 40  |
| E     | источники: сколько разных доменов подтверждают идею, до трёх       | 20  |
| U     | доля идей без повторов                                             | 10  |
| B     | доля исполнимых принятых идей, по которым прошла проверка продукта | 15  |
| C     | цена идеи относительно резерва (только у платных провайдеров)      | 5   |
| D     | доля заказов, выданных без ручной проверки (от трёх заказов)       | 10  |

Части, которые не применимы, не учитываются. При равном балле выше старший агент: копия не вытесняет родителя на ничьей.

## Когда отбор проходит

Нужно всё сразу: отбор включён, ферма работает, сезон открыт, ровно четыре агента, у каждого не меньше K идей в поколении (по умолчанию 6, для показа 2), разрыв между вторым и третьим не меньше 50 (5 пунктов), в этом поколении ротации ещё не было. Иначе раунд записывается как «ждём» с причиной.

Проверку ставит планировщик, когда у всех хватает идей (не чаще `evolution_rounds_per_day`), и кнопка «Провести отбор сейчас» (`POST /api/office/agents/evolve`).

## Что делает ротация

Одна транзакция (`runEvolutionRound`):

1. Два худших агента уходят в архив с причиной («Балл 333 из 1000: принято 0 из 3 идей»). Их идеи, продукты и заказы остаются.
2. Два лучших получают по копии. Копия наследует параметры с одной мутацией: заменить отрасль на наименее разведанную, сменить порог источников, тон, охват или осторожность. Параметр выбирается детерминированно и не повторяет прошлую мутацию родителя. Текст инструкции собирает сервер из параметров; ни модель, ни владелец его не пишут.
3. Поколение растёт на 1. Начало сезона не меняется: отбор не продлевает 28 дней.
4. Повторный вызов для того же поколения возвращает тот же раунд. Частичный уникальный индекс не даст второй ротации даже при гонке двух worker.

## Имена

Основатели: Разведчик А, Б, В, Г. Копия: буква основателя и номер поколения, например А2. Имена считает сервер и отдаёт в `OfficeAgent.name`.

## Честные ограничения

Отбор измеряет работу агентов, а не будущие продажи. Агент может подстраиваться под метрику, например приносить осторожные идеи; уникальность и критик это частично сдерживают. Бесплатные модели ошибаются, поэтому балл на малой выборке шумный.
