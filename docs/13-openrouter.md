# Подключение OpenRouter

Сервис работает через бесплатные модели OpenRouter или локально через Ollama. Исследование, сборка услуг, выполнение заказов и проверка текста используют один адаптер. Поиск остаётся в SearXNG.

Поддерживаются **только бесплатные модели**: `openrouter/free` или идентификатор вида `vendor/model:free`. Список и доступность моделей меняются; качество нужно проверять на своих обезличенных примерах.

## Проверенная настройка (06.10.2026)

Повторная проверка 07.10.2026 подтвердила живые генерации и выпуск услуг описания и оформления публикаций в отдельной тестовой БД. Исследование FAQ остановилось на `MODEL_SCHEMA_INVALID`; в ночном запуске рабочей базы был `OPENROUTER_HTTP_403`. Успешное подключение не гарантирует стабильности каждого запроса. [Свежий протокол](reports/2026-10-07-acceptance.md).

```dotenv
MODEL_PROVIDER=openrouter
OPENROUTER_API_KEY=запишите_ключ_локально
OPENROUTER_MODEL=dots-studio/dots-3-note-preview:free
OPENROUTER_REASONING_EFFORT=low
SEARCH_PROVIDER=searxng
```

`openrouter/free` с этим адаптером сейчас не работает: после фильтра `data_collection=deny` бесплатный маршрутизатор не находит эндпоинта с нужными параметрами и возвращает 404. Из бесплатных моделей ограничение на сбор данных проходит `dots-studio/dots-3-note-preview:free`. Другие (`nvidia/nemotron-*`, `liquid/lfm-*`) требуют разрешить обучение на запросах, `google/gemma-4-*` возвращали ошибку провайдера. Ослаблять запрет сбора данных ради выбора модели нельзя без отдельного решения владельца.

## Настройка локального стенда

1. Создайте ключ в кабинете OpenRouter и запишите его в локальную `.env`. Не добавляйте ключ в Git и не отправляйте его в чат.
2. Укажите параметры из блока выше.
3. Пересоздайте приложение и обработчик (простой `restart` не читает изменённую `.env`):

   ```bash
   docker compose -f compose.yaml -f compose.local.yaml --profile app up -d --build web worker observer
   ```

4. Проверьте в «Настройках» отметку «OpenRouter · бесплатные модели». Выполните одно ручное исследование и тестовый заказ.

`npm run local:setup` возвращает `MODEL_PROVIDER=ollama`. После него OpenRouter нужно включить заново.

Смена провайдера не снимает паузу, аварийный стоп, закрытое окно исследования или серверный запрет `AUTONOMY_ENABLED=false`. История, заказы и резервы сохраняются. Начатое задание нельзя безопасно продолжать с ответами другой модели: дождитесь завершения перед переключением.

## Ограничения адаптера

- Запрос идёт только на `https://openrouter.ai/api/v1/chat/completions`. Перенаправления, инструменты и плагины отсутствуют.
- Запрашивается `json_object`, схема передаётся в системном промпте. Каждый ответ проверяется схемой проекта на сервере. Строгий `json_schema` на стороне провайдера отключён: с ним модель копировала исходный текст без списка и не проходила формат услуги.
- Цена входа, выхода и запроса ограничена нулём, переходы к запасным провайдерам выключены, `data_collection=deny`, `require_parameters=true`. Название модели проверяется до запроса.
- Лимит вывода 8 000 токенов, общий для рассуждения и ответа. Бесплатные модели с рассуждением часто превышали прежние 2 800 токенов и не дописывали JSON. `OPENROUTER_REASONING_EFFORT` сокращает рассуждение, но провайдер выполняет его не всегда.
- Если ответ не прошёл схему, разрешена одна попытка исправления с перечнем ошибок, как у Ollama. Она выполняется только после подтверждённой нулевой цены первого ответа; токены обеих попыток суммируются. Оценка расходов не отправляется на исправление.
- Каждый вызов сначала фиксируется в PostgreSQL. Повтор успешного вызова читает сохранённый ответ. Ошибка HTTP, ошибка провайдера в теле ответа или обрыв не вызывают повторной отправки: задание останавливается, заказ уходит на ручную проверку.
- Токены и фактическая стоимость сохраняются из `usage`. Если провайдер считает рассуждение вне `completion_tokens`, доля рассуждения сохраняется как неизвестная. Ненулевая стоимость сохраняется в целых микродолларах, ответ блокируется, следующие вызовы требуют разбора.

Бесплатные модели имеют квоты и могут возвращать 429 или быть временно недоступны. Приложение не покупает кредиты и не обходит квоты.

## Результат живой проверки 06.10.2026

Все вызовы отчитались нулевой стоимостью.

- Заказы через OpenRouter после исправлений: описание термокружки, описание лампы с тремя отрицаниями и FAQ мастерской выданы с PASS, факты и отрицания сохранены. Отклонённые ранее ответы остались на ручной проверке в истории.
- Исследование прошло все роли и выпустило описание товара V5. Другие запуски отклонены критиком, проверкой контрольного примера или схемой: это работа контроля, а не сбой.
- Модель-превью нестабильна: отдельные вызовы рассуждают до лимита или отдают JSON вне схемы. Перед выбором другой модели повторите проверку.

Платные модели OpenRouter запрещены сервером. Их подключение требует отдельного режима с тарифом, резервированием стоимости и денежными лимитами.

Подключение модели не открывает публичные продажи. Сервис проверяет гипотезы, создаёт до трёх текстовых услуг и исполняет тестовые заказы в закрытом кабинете.
