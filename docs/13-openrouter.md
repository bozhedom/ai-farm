# Подключение OpenRouter

Сейчас сервис можно запускать без облачных ключей через Ollama и SearXNG. OpenRouter подготовлен как следующий вариант модели: исследование, сборка услуг, выполнение заказов и проверка текста используют тот же адаптер. Поиск остаётся в SearXNG.

Первое подключение поддерживает **только бесплатные модели**. По умолчанию выбран `openrouter/free`: OpenRouter подбирает доступную бесплатную модель с нужными возможностями. Можно указать конкретный идентификатор вида `vendor/model:free`. Список и доступность моделей меняются; качество нужно проверить на своих обезличенных примерах. [Бесплатный маршрутизатор OpenRouter](https://openrouter.ai/openrouter/free).

## Настройка локального стенда

1. Создайте ключ в кабинете OpenRouter и запишите его в локальную `.env`. Не добавляйте ключ в Git и не отправляйте его в чат.
2. Укажите:

   ```dotenv
   MODEL_PROVIDER=openrouter
   OPENROUTER_API_KEY=запишите_ключ_локально
   OPENROUTER_MODEL=openrouter/free
   SEARCH_PROVIDER=searxng
   ```

3. Для уже настроенного локального стека пересоздайте приложение и обработчик:

   ```bash
   docker compose -f compose.yaml -f compose.local.yaml --profile app up -d --build web worker observer
   ```

4. Откройте приложение, проверьте выбранную модель в «Настройках» и выполните одно ручное исследование при выключенном расписании. Затем проверьте пример услуги и тестовый заказ. После проверки включите расписание, если нужна ежедневная работа.

Смена провайдера не снимает паузу, аварийный стоп, закрытое окно исследования или серверный запрет `AUTONOMY_ENABLED=false`. История, заказы и резервы сохраняются. Начатое задание нельзя безопасно продолжать с ответами другой модели: дождитесь завершения перед переключением.

Наличие ключа в `.env` ещё не подтверждает доступность облачной модели. Первый успешный ответ проверяет фактическое подключение. Без подходящего бесплатного маршрута задание остановится с ошибкой; локальная модель или платный маршрут не подставляются автоматически.

## Ограничения адаптера

- Запрос идёт только на `https://openrouter.ai/api/v1/chat/completions`. Перенаправления, дополнительные инструменты и плагины отсутствуют.
- Сервер передаёт `json_schema` со строгим режимом и требует поддержки параметров. Полученный JSON повторно проверяется схемой проекта. Усечённый ответ, отказ, неподходящий формат или запрос инструмента не выдаются как успешный результат. [Структурированные ответы](https://openrouter.ai/docs/guides/features/structured-outputs).
- Название модели проверяется до запроса. Максимальная цена входа, выхода и запроса равна нулю; переходы к запасным провайдерам выключены. Политика `data_collection=deny` ограничивает выбор провайдеров. Если совместимого бесплатного провайдера нет, ограничения сохраняются. [Маршрутизация и ограничения цены](https://openrouter.ai/docs/guides/routing/provider-selection).
- Каждый вызов сначала фиксируется в PostgreSQL. Повтор того же успешного вызова читает сохранённый ответ. Неясный исход не вызывает автоматическую повторную отправку. Денежный резерв модели равен нулю; общие лимиты и правила паузы продолжают действовать.
- Токены и фактическая стоимость сохраняются из `usage`, включая неудачную проверку текста. Отсутствующая стоимость не подменяется нулём. Если API неожиданно сообщает ненулевую сумму, она сохраняется в целых микродолларах, ответ блокируется, следующие вызовы OpenRouter требуют разбора. Старые расходы не стираются. [Учёт usage и стоимости](https://openrouter.ai/docs/cookbook/administration/usage-accounting).

Бесплатные модели имеют квоты и могут возвращать 429 или быть временно недоступны. Проверяйте текущие условия в кабинете и [документации лимитов](https://openrouter.ai/docs/api_reference/limits). Приложение не покупает кредиты и не обходит квоты.

## Проверки и дальнейшая работа

Адаптер проверяется на ответах-фикстурах: строгая схема, ошибки, нулевая цена, учёт токенов, защита от повторной отправки и блокировка неожиданного списания.

Живая проверка 06.10: `openrouter/free` возвращает 404, потому что после фильтра `data_collection=deny` нет бесплатных эндпоинтов со строгим `json_schema`. Из бесплатных моделей с поддержкой схемы ограничения проходит только `dots-studio/dots-3-note-preview:free`. Это модель с рассуждениями: в исследовании она расходует лимит 2 800 токенов до конца JSON. Заказы получили ответ неподходящего формата или ошибку провайдера в теле HTTP 200. Принятых результатов нет, стоимость 0. Список бесплатных моделей меняется; перед следующей попыткой проверьте его заново.

Платные модели OpenRouter пока запрещены сервером. Их подключение требует отдельного режима с выбранным тарифом, резервированием максимальной стоимости, денежными лимитами и проверкой реального usage. Одной замены имени модели недостаточно.

Подключение модели не открывает публичные продажи. По текущему плану сервис проверяет гипотезы, создаёт до трёх текстовых услуг и исполняет тестовые заказы в закрытом кабинете. Посетители, законная оплата и выход на рынок остаются следующим этапом.
