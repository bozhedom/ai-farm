# Как ферме принимать оплату (исследование 21.10.2026)

Модель деньги не трогает: сервер создаёт ссылку на оплату заказа, клиент платит, уведомление провайдера подтверждает оплату, сервер перепроверяет сумму, валюту и номер заказа. Ниже — выводы исследования по открытым источникам; перед подключением условия нужно перепроверить в кабинете провайдера. Это не юридическая консультация.

## Рекомендация

| Кто платит                    | Что использовать                                                                | Почему                                                                                                                                |
| ----------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Клиенты из РФ, владелец — НПД | **Robokassa + Робочеки СМЗ**; запасной вариант — Prodamus                       | берут самозанятых без ИП, чеки сами уходят в «Мой налог»; комиссия около 3,4–3,9 % ([тарифы](https://robokassa.com/payments/tarify/)) |
| Клиенты из РФ, владелец — ИП  | ЮKassa, T‑Касса или CloudPayments                                               | дешевле (СБП 0,4–0,7 % у ЮKassa), но нужны расчётный счёт и касса по 54‑ФЗ                                                            |
| Иностранные клиенты           | **Уже сделанный адрес USDT на Bybit** (`PAYMENT_USDT_*`, ключ только на чтение) | крипто-шлюзы недоступны или опасны для резидента РФ; 282‑ФЗ (с 01.09.2026) допускает крипторасчёты по внешнеторговым сделкам          |
| Фриланс-площадки              | оплата внутри площадки, вывод делает владелец вручную                           | оплата мимо площадки — повод для блокировки аккаунта                                                                                  |

## Чего избегать

- **ЮKassa для самозанятых** — по changelog ЮKassa поддержка самозанятых прекращена с 29.12.2025 ([источник](https://yookassa.ru/developers/payment-acceptance/receipts/self-employed)).
- **Antilopay** — по правилам сервиса получатель только ЮЛ или ИП; официальная документация с этого компьютера не открылась.
- **NOWPayments** (Россия в запрещённых юрисдикциях), **Cryptomus / Heleket** (санкции Великобритании 08.10.2026), **Binance Pay** (Binance ушла из РФ), Boosty (нет API).
- Upwork и Fiverr для резидентов РФ фактически закрыты, вывод в российские банки невозможен.

## Налоги и крипта

- Резидентам РФ платить криптой за услуги нельзя — адрес USDT только для иностранных клиентов (так и написано в кабинете).
- **Самозанятость несовместима с криптой**: 422‑ФЗ (в редакции 418‑ФЗ) лишает права на НПД тех, кто покупает или продаёт цифровую валюту. Доход в USDT проводить через ИП на УСН или декларацию 3‑НДФЛ по курсу ЦБ на дату поступления; посоветуйтесь с бухгалтером.
- Ферма учитывает USDT отдельно и не пересчитывает его в рубли; доходом поступление становится только после отметки владельца.

## Что сделать владельцу

1. Выбрать режим: НПД (регистрация в «Мой налог») или ИП на УСН 6 %.
2. Зарегистрировать магазин в Robokassa (или Prodamus при отказе), пройти модерацию: сайт с офертой, политикой персональных данных, контактами и описанием услуг. Деятельность описывать как «подготовка текстов, редактура, перевод, цифровые материалы».
3. Дать Робочекам доступ к кабинету «Мой налог», выбрать алгоритм подписи SHA256, включить тестовый режим.
4. Внести ключи самому на сервере в `.env` (в чат не присылать): `ROBOKASSA_MERCHANT_LOGIN`, `ROBOKASSA_PASSWORD1`, `ROBOKASSA_PASSWORD2`, `ROBOKASSA_TEST_PASSWORD1`, `ROBOKASSA_TEST_PASSWORD2`, `ROBOKASSA_HASH_ALGO`, `ROBOKASSA_IS_TEST`.

Интеграция Robokassa в ферме **ещё не сделана**: её делаем после выбора владельца и получения тестовых ключей, сначала в тестовом режиме. Тестовые платежи доходом не считаются.
