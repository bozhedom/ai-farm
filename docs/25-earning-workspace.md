# Направления и их готовность

Кабинет: https://farm.89.19.215.46.sslip.io/office/earnings. Статусы ниже сверены с сервером 3 ноября 2026 года. Текущие подключения и активность показываются вверху страницы «Направления»; подробная [инструкция пользователя](38-user-guide.md) объясняет действия в кабинете.

## Реализовано и подключено

| Направление                    | Статус                  | Подключение и фактический режим                                                                                                                  |
| ------------------------------ | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Bybit Spot                     | **работает**            | Приватный ключ принят, Live запущен с капиталом 20 USDT. На проверке было две исполненные заявки. Прибыльность не подтверждена.                  |
| OKX, Binance, Bitget Spot Live | **требует подключения** | Код адаптеров есть; приватных Live-подключений нет. Публичные данные и Paper не заменяют торговый доступ.                                        |
| Paper Spot                     | **тестовый режим**      | OKX и Binance активны; Bybit и Bitget на защитной паузе. Виртуальные средства.                                                                   |
| Сетка и DCA                    | **тестовый режим**      | Реализованы только в Paper. Доступность стратегии не означает, что она выбрана в активном портфеле.                                              |
| Арбитраж                       | **тестовый режим**      | Paper активен, Live не подключён. Нужны отдельные счета на нескольких биржах, сверка активов, средства на обеих сторонах и разрешение владельца. |
| Фандинг                        | **тестовый режим**      | Paper активен. Исполнитель хеджа Bybit отделён от обычного спота; ему нужны собственные доступы и капитал.                                       |
| DeFi / Aave                    | **тестовый режим**      | Paper активен. Работа адаптера проверена локально; реальный кошелёк не подключён.                                                                |
| Kalshi                         | **требует подключения** | Адаптер реализован, аккаунт не подключён, исполнение не запущено. Доступность площадки для владельца проверяется отдельно.                       |
| Polymarket                     | **не используется**     | Только публичные данные, исполнитель контрактов отсутствует.                                                                                     |
| Публичные рыночные мониторы    | **работает**            | Чтение цен, фандинга, DeFi и рынков прогнозов без отправки заявок.                                                                               |
| Поиск идей и текстовые услуги  | **работает**            | Модельные исследования, контроль качества и выдача текста. Действуют бюджеты и очередь.                                                          |
| Оплата услуг и сервисный API   | **тестовый режим**      | Sandbox / Sepolia; настоящего платёжного провайдера нет. API требует входа владельца и не является x402.                                         |
| Kwork через браузер            | **работает**            | Вход и одна отправка подтверждены; оплаченный результат пока не подтверждён. Другие площадки требуют подключения.                                |
| Торговый менеджер              | **тестовый режим**      | Предлагает Paper-эксперименты; не запускает Live и не снимает остановки.                                                                         |
| Выпуск токенов, MEV, x402      | **не используется**     | Отдельных исполнителей этих сценариев нет.                                                                                                       |

Слова «работает» относятся к конкретной функции в последнем столбце. Это не обещание автономного заработка. Переключение вкладки в кабинете не подключает аккаунт, не выделяет капитал и не разрешает реальные операции.

## Что означает активность

«Активно» означает включённый процесс при доступном worker; режим указан отдельно. «Не активно» может означать отсутствие подключения, остановку, отсутствие выбранной стратегии или выключенное расписание. При сбое связи кабинет отмечает, что показывает последнее известное состояние.

Live включается только владельцем после отдельных настроек и проверки доступа. Ожидание прибыльного Paper и обязательных Demo-циклов отменено 28 октября; ключи, разрешения, проверка капитала, лимиты и запрет вывода сохраняются. Подключение Bybit Spot не подключает автоматически фандинг или арбитраж.
