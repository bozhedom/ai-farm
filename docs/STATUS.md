# Состояние проекта · 24.09.2026

## Итог текущего блока

Рабочий **закрытый экспериментальный стенд**, не готовый бизнес с реальной выручкой. Созданы приватный репозиторий [bozhedom/ai-farm](https://github.com/bozhedom/ai-farm), Nuxt-приложение, PostgreSQL и отдельный worker. Полный стек, включая локальную модель и живой поиск, запущен локально в Docker по адресу **http://localhost:3210**. Пароль владельца находится в `.env`, поле `OWNER_PASSWORD`.

Секреты, дампы и браузерные артефакты в Git не включены. Старые DOCX сохранены без изменений. Приоритет имеют новый план, мастер-промпт и этот статус.

## Реализовано и проверено

- Общий мастер-промпт для каждого модельного вызова, узкие роли, JSON-схемы, проверка текстов и ограниченные инструменты.
- Автономное суточное исследование, отдельный критик, сборка конфигураций до трёх текстовых сервисов. Контрольный ввод, короткий ввод и известная prompt-injection проверяются до выпуска.
- Общая память последних выводов без данных заказчиков. Задание сохраняет состав шаблонов и стратегию для продолжения после сбоя.
- Подключены Ollama 0.34.3 / Qwen3 4B и локальный SearXNG. Живой поиск и реальная генерация проверены. Облачные ключи не требуются. Yandex остаётся дополнительным провайдером, его адаптеры без ключей не проверены на живом API.
- Пульт показывает текущую роль, стратегию, задачу, время, реальный счётчик символов, историю этапов и их результаты. Простой и потеря связи отображаются отдельно. Работает обновление раз в две секунды.
- До трёх дополнительных исследований в UTC-сутки с интервалом от пяти минут; параллельные нажатия используют одно задание. Остаток запусков виден в панели.
- При ошибке формата допустима одна локальная попытка исправления; денежные оценки этим механизмом не корректируются. Превышение бюджета сохраняется в гипотезе и запрещает выпуск. Кеш демопровайдера нельзя выдать за живой ответ после смены провайдера.
- Новая принятая гипотеза может обновить версию существующего продукта. Полная история версий и старые снимки заказов сохраняются. На карточке доступен контрольный результат.
- Постоянная очередь PostgreSQL, идемпотентные задания, аренда задачи / heartbeat, ограниченные повторы. Устаревшие суточные задания пропускаются после паузы, чтобы не запускать накопившиеся расходы.
- Отдельные циклы исследования, обработки заказов и сверки платежей внутри worker.
- Общий дневной и месячный бюджет, защищённая часть для заказов, атомарные резервы, консервативный учёт неизвестного исхода API-вызова.
- Вход владельца с серверной сессией, ограничение попыток, проверка Origin, закрытые API, лимиты размера ввода, сохранение версии продукта и стратегии в заказе.
- Русскоязычная адаптивная панель, гипотезы и источники, стратегии, тестовая витрина, заказы, журнал, расходы и TXT-выдача.
- Sandbox: подтверждение тестового события, одно задание на выдачу, отдельная проверка результата. Реальные средства не переводятся.
- Sepolia: адаптер read-only RPC, точная сумма wei, hash, сеть, получатель, статус, время счёта, canonical block, подтверждения и защита от повторного использования транзакции. **Проверен на моделируемых RPC-ответах, не на реальном переводе.**
- Недельный отчёт HOLD без реальной выручки. Через 28 дней без подтверждённых продаж исследования останавливаются; заказы сохраняются. Новое окно открывает владелец.
- Отбор 50% на явно обозначенных тестовых данных: два участника архивируются, появляются две копии лидеров с parent_id; четыре активных места сохраняются. В браузерной проверке выполнена смена поколения 1 → 2.
- Мягкая пауза, аварийный стоп, сохранение оплаты при остановленном worker и выдача после его запуска.
- Docker Compose, healthcheck всех шести служб, ежедневные копии, ручной backup и восстановление в отдельную временную БД. Конфигурация Caddy для собственного VPS подготовлена.
- GitHub Actions: форматирование, TypeScript, модульные и интеграционные тесты, production build.

## Фактический живой прогон

24.09.2026 выполнено реальное исследование: шесть веб-источников → Qwen3 → критик → серверная проверка бюджета. Задание завершилось за 3 мин 57 с, гипотеза **отклонена**: модель оценила расходы в 1 200 ₽ при лимите 40 ₽. Критик ошибочно считал это допустимым; код независимо заблокировал публикацию. Оценка не уменьшалась для прохождения проверки.

Два предварительных запуска обнаружили ошибку первоначальной схемы: она запрещала само число расходов выше 40 ₽. Это исправлено: высокая оценка теперь сохраняется, а отказ — отдельное решение контролёра бюджета. Неудачные запуски и диагностический журнал сохранены. Все три дополнительных исследовательских слота за 24 сентября использованы; суточный запуск остаётся включён, тестовые заказы доступны.

Затем выполнен заказ `51d97083-ee14-4d2f-bd16-0183c4b294bd`: sandbox-оплата → реальная генерация Qwen3 → отдельная проверка PASS → выдача текста и TXT. Модельные этапы заняли около 41 с. Использована **существующая демоконфигурация** сервиса описаний; сам ответ — реальный вывод модели. Исследование этого дня **не создало новый продукт**. Сборка / обновление продуктов проверены интеграционными тестами с демопровайдером; полный живой путь после принятой гипотезы ещё предстоит проверить.

71 автоматический тест (48 unit + 23 integration), typecheck, production build, форматирование. Проверены desktop / mobile, отсутствие горизонтального переполнения на 390 px, активные роли, выдача заказа и реакция на разрыв связи: вращение прекращается, появляется предупреждение. Backup восстановлен в отдельную временную БД. Подробности и ограничения — [протокол](reports/2026-09-24-live.md).

## Что ещё НЕ проверено или не входит в текущую версию

1. Живые модельные ответы Yandex, доступность выбранного URI, фактический тариф, качество результатов и права сервисного аккаунта. Нет API-ключей — проверяется после подключения.
2. Настоящая тестовая транзакция Sepolia. Создан отдельный тестовый адрес утилитой `npm run wallet:test`; публичный RPC подтвердил Sepolia и нулевой баланс. Ключ лежит только в `.secrets` (0600), не в контейнерах. Перевод ещё не выполнен: нет тестового ETH. Оплата остаётся sandbox.
3. Удалённый VPS, домен, HTTPS и внешний мониторинг. Сейчас развёрнуто на локальной машине. Уведомления — панель и журнал; email / Telegram не подключены.
4. 48 часов наблюдения, нагрузка и восстановление на целевом сервере. Нельзя считать их выполненными за текущий сеанс.
5. Публичная продажа незарегистрированным покупателям, персональные ссылки / аккаунты, правовые документы продавца, чеки, реальный эквайринг или законная криптосхема. Сейчас витрина закрыта сессией владельца.
6. Боевые когорты посещений, возвраты, комиссии и автоматическое применение финансового отбора. Функция порогов протестирована; реальные метрики не собираются, live-ротация не включена, поскольку поддерживаются только тестовые платежи. Показатель реальной выручки намеренно равен нулю.
7. Произвольное создание / деплой программ, новые интеграции, самостоятельная реклама, регистрация аккаунтов, хранение приватных ключей в приложении, обмен и вывод денег. Эти операции отсутствуют.

Фильтры текста и критик не являются юридической экспертизой и не дают абсолютной защиты от prompt injection. Узкие операции и отсутствие mainnet — программные ограничения. Реальные продажи требуют отдельно проверенной схемы для конкретного продавца.

## Что нужно от владельца для следующего блока

Для удалённой установки нужны VPS, IP и имя SSH-пользователя. Для текущей локальной модели — от 4 vCPU / 8 GB RAM, лучше 12 GB, от 40 GB диска. Публичный ключ подготовлен в `.secrets/vps_deploy.pub`: добавьте его при создании сервера. Домен можно подключить позже. Доступы Yandex для нынешнего режима не нужны. Порядок запуска — [инструкция](03-setup.md), просмотр работы — [сценарий демонстрации](04-live-demo.md). Секреты в чат не передаются.

Далее: проверить качество на нескольких разных исходных материалах и сценариях → получить принятую живую гипотезу и пройти её сборку / QA → провести один Sepolia перевод после получения тестовых монет → развернуть закрытый стенд на VPS → включить внешнее наблюдение → провести 48-часовую приёмку. Любые реальные продажи рассматриваются отдельным этапом.
