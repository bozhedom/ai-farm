# AI Farm

**Начать здесь: [руководство для сдачи, самостоятельной проверки и запуска услуг](docs/15-delivery-and-business.md).** Результаты аудита и ограничения: [протокол 08.10.2026](docs/reports/2026-10-08-audit.md).

Сервис для проверки идей текстовых услуг. Сам ищет открытые источники и потенциальные запросы заказчиков, предлагает услугу, проверяет её на примере и добавляет в каталог. Затем принимает тестовый заказ, готовит текст и отдельно проверяет результат. Суточное расписание поддерживает чередование направлений или полный последовательный обход; оплаченные тестовые заказы выполняются по мере поступления.

Двенадцать видов услуг: описание товара, FAQ, публикации, редактура, перевод, краткое содержание, ответ клиенту, текст страницы, деловое предложение, инструкция, мини-урок и текст вакансии. В бесплатном режиме публикации ограничены тремя вариантами оформления полного исходника. История, версии услуг, расходы и незавершённые заказы сохраняются. Проблемный тестовый заказ можно явно закрыть с причиной без фиктивной выдачи.

## Запустить локально

Нужны Node.js 24, Docker Compose, от 4 CPU / 8 GB RAM и несколько гигабайт для модели.

```bash
npm ci
npm run local:setup
```

Откройте **http://localhost:3210**. Пароль находится в поле `OWNER_PASSWORD` файла `.env`. Команда запускает Ollama с Qwen3 4B, SearXNG, приложение, обработчик заданий, резервные копии и наблюдение. За модельные и поисковые API платить не нужно.

Прежние пауза, заказы и денежные лимиты сохраняются. При необходимости нажмите **«Продолжить работу»**, затем **«Включить автозапуск»**. Ключи облачных моделей для локального режима не используются. Обновление на VPS эта команда не выполняет.

## Что посмотреть первым

1. В «Направлениях» запустите исследование одного типа или всех 12. Оно ищет источники, проверяет идею и пробует собрать услугу. Модель может работать несколько минут; отказ тоже сохраняется с причиной.
2. Откройте «Услуги», выберите услугу и подставьте пример исходных данных.
3. Создайте тестовый заказ и подтвердите тестовую оплату. В режиме sandbox деньги не переводятся.
4. Дождитесь проверки текста, прочитайте результат и скачайте TXT. Если проверка не пройдена, заказ покажет причину.
5. В «Клиентах» проверьте найденные ссылки и сохраните подходящие кандидаты. Настройте охват суточного автозапуска; работа продолжается, пока компьютер включён и Docker запущен.

## Откуда может появиться доход

Идея услуги: покупатель даёт свой материал и платит за готовый текст. Чтобы проверить такую идею на рынке, нужны качественные результаты, понятное предложение, посетители и разрешённый способ оплаты.

**Сейчас это закрытый тестовый сервис. Реальной выручки в нём нет.** Он помогает исследовать рынок, находить потенциальные запросы, выпускать услуги и выполнять заказы. Поисковые кандидаты не являются подтверждёнными покупателями; связь с ними и сделки остаются у владельца. Sandbox и Sepolia используют только тестовые платежи. Публичная продажа и настоящая оплата требуют отдельной интеграции продавца.

Подключение OpenRouter описано в [отдельной инструкции](docs/13-openrouter.md). На текущем локальном стенде он уже настроен. `npm run local:setup` переключает модель на Ollama; для просмотра работающего OpenRouter повторно запускать эту команду не нужно. Ключ хранится локально в `.env`; отправлять его в чат не нужно.

## Быстрая демонстрация без модели

Для новой установки с `MODEL_PROVIDER=demo`:

```bash
node scripts/setup.mjs
docker compose --profile app up -d --build
```

Деморежим показывает механизм на готовых примерах, без интернет-исследования. `setup` сохраняет существующий `.env`, поэтому на уже настроенном проекте режим сам не меняется. Подробные команды разработки, проверки и восстановления находятся в [инструкции запуска](docs/03-setup.md).
