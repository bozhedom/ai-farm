# AI Farm · лаборатория автономных продуктов

Один владелец, до трёх текстовых сервисов, четыре конкурирующие стратегии. Система исследует гипотезы, ищет возражения, собирает продукты из разрешённых шаблонов и выполняет тестовые заказы. Работа продолжается по расписанию; решения, расходы и ошибки сохраняются.

**Это экспериментальный пилот за 30 000 ₽ / 20 рабочих дней. Прибыль не гарантируется. Криптооплата — только sandbox / Ethereum Sepolia, без настоящих денег.**

## Быстрый запуск

```bash
node scripts/setup.mjs
docker compose --profile app up -d --build
```

Откройте **http://localhost:3210**. Пароль — `OWNER_PASSWORD` в `.env`. При первом запуске worker самостоятельно готовит два демосервиса. Для разработки: `npm ci`, `npm run db:migrate`, `npm run dev` и отдельно `npm run worker` при запущенной БД.

Для настоящего исследования без облачных ключей: `npm ci` → `npm run local:setup`. Команда установит Ollama с Qwen3 4B и SearXNG, переключит провайдеров и запустит приложение. Нужны от 4 CPU / 8 GB RAM; первый запуск скачивает несколько гигабайт. В панели нажмите «Новое исследование»: текущая роль, время, полученные символы и проверенные результаты появятся в пульте.

Yandex остаётся облачной альтернативой после заполнения доступов. Оплата поддерживает только `sandbox` / `sepolia`; `npm run wallet:test` создаёт отдельный тестовый адрес без передачи ключа приложению. Стенд и заказы закрыты сессией владельца.
